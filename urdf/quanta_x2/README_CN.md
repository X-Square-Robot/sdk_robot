# Quanta X2 机器人描述文件

[English](README.md) | [中文](README_CN.md)

本目录预留给 Quanta X2 资源元数据。目前尚未登记经过确认的资源版本和压缩包，
本目录不表示当前 SDK Release 已提供 Quanta X2 URDF 下载。

资源就绪后，`resource.json` 会记录版本、Release 附件名、压缩包目录和 SHA-256。
请从对应 SDK Release 下载本机型 ZIP，并按[下载说明](../README_CN.md)使用。
实际 URDF 和网格文件通过 Release 附件分发，不进入 Git。
