# Quanta X2 robot description

[English](README.md) | [中文](README_CN.md)

This directory is reserved for Quanta X2 resource metadata. A verified
resource version and archive have not been registered in this SDK release yet.
No Quanta X2 URDF download is currently promised by this directory.

When available, `resource.json` will specify the version, Release asset name,
archive layout and SHA-256. Download that model's ZIP from the matching SDK
Release and follow [the download guide](../README.md).
Actual URDF and mesh files are distributed as Release attachments, outside Git.
